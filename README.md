# Nekro Plugin: QQ空间

适用于 NekroAgent 的 QQ 空间功能插件。

## 功能

- 查看访客
- 查看 / 点赞 / 评论 / 回复说说
- 删除自己的说说
- 表白墙投稿、匿名投稿、撤稿、审核（过稿 / 拒稿）
- 自然语言发说说（通过 AI 沙盒工具发布）
- 定时发说说、定时评论好友动态
- 聊天概率触发评论说说
- LLM 沙盒工具：`qzone_view_feed`、`qzone_publish_feed`

## 发说说说明

当前不再提供独立的发说说斜杠指令，例如 `/发说说`、`/自然发说说`、`/人设发说说` 已移除。

发说说方式：

- 自然语言：直接对机器人说类似“帮我发一条说说：今天天气不错”，AI 会调用 `qzone_publish_feed` 生成并发布。
- 定时发送：默认每天 `22:00` 前后自动生成并发布一条说说，并通知管理员。

## 定时任务

| 任务 | 默认时间 | 配置 |
| --- | --- | --- |
| 自动发说说 | 每天 `22:00`，前后随机 `±600` 秒 | `PUBLISH_CRON` / `PUBLISH_OFFSET` |
| 自动评论好友动态 | 每天 `08:00`，前后随机 `±600` 秒 | `COMMENT_CRON` / `COMMENT_OFFSET` |

留空对应 Cron 配置可关闭该定时任务。

## 配置说明

在 Nekro 后台插件配置中设置主要参数：

- `MANAGE_GROUP`：投稿审核和定时任务通知发送到的群号，留空则私聊管理员。
- `ADMIN_USERS`：管理员 QQ 号列表。
- `MODEL_GROUP`：写说说、评论、回复使用的 LLM 模型组。
- `POST_PROMPT`：定时发说说的生成提示词，默认根据人设和群聊经历生成。
- `COMMENT_PROMPT`：评论提示词，默认根据人设生成评论。
- `REPLY_PROMPT`：回复提示词，默认根据人设生成回复。
- `PUBLISH_CRON`：自动发说说时间，格式 `HH:MM`，默认 `22:00`。
- `COMMENT_CRON`：自动评论时间，格式 `HH:MM`，例如 `08:00`。
- `READ_PROB`：聊天消息触发评论说说的概率，默认为 `0`。
- `SEND_ADMIN`：触发读说说时是否仅通知管理员，默认开启。
- `LIKE_WHEN_COMMENT`：评论说说时是否自动点赞。

## 部署

1. 将本目录放到 Nekro 本地插件目录，例如：

   ```text
   /root/srv/nekro_agent/plugins/workdir/nekro_plugin_qzone
   ```

2. 安装依赖：

   ```bash
   docker exec nekro_agent /app/.venv/bin/pip install beautifulsoup4 croniter
   ```

3. 重启 Nekro 并在后台启用插件。
